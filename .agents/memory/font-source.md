The Arabic font collection in this project was sourced from https://arbfonts.com/.

**Why:** The user confirmed this as the source site.

**How to apply:** Refer to arbfonts.com as the catalog's source when auditing provenance, attribution, or license information.

For additions requiring a specific license, a search-result match is not sufficient proof. Verify the individual font page's stated license, check for conflicting component licenses, and compare the actual family name against the loaded catalog before counting it as new.

**Why:** Site searches for license terms also return unrelated title matches, weights, legacy versions, and pages whose license wording is incomplete.

**How to apply:** Record only families whose page explicitly confirms the required license and whose family is not already represented in the catalog; treat unclear or mixed terms conservatively.
