---
name: Thumbnail workspace
description: Product UX decision for the YouTube thumbnail generator workspace
---

The thumbnail generator uses one responsive workspace after sign-in: creation controls and the generated result stay together on desktop, while the same sections stack vertically on mobile. The public page remains a short SEO-aware entry point.

**Why:** Keeping the workflow on one screen reduces navigation and makes the tool usable on both desktop and phone without duplicating the generation flow.

**How to apply:** Preserve the two-panel desktop / one-column mobile structure. Do not add fake account states; connect real authentication and persistent project history before presenting saved-project features.
