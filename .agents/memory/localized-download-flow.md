---
name: Localized download flow
description: User-approved navigation behavior for English and French font download buttons
---

English and French font-list buttons should open the corresponding font detail page in the visitor’s language, with actual file download available there. Use “View & Download” and “Voir et télécharger” for the navigation buttons.

**Why:** The user requested the same details-before-download experience they expect from the Arabic site and approved labels that distinguish navigation from immediate download.

**How to apply:** Preserve this flow in directory, category, and collection listings. Do not turn the final download button on a font’s detail page into another navigation step.
