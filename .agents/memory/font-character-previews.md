---
name: Font character previews
description: Decision for combining SEO-friendly character text with visual font specimen images.
---

Keep the character map as readable HTML and use a generated image as a supplementary visual preview. Roll out images gradually instead of creating them for the entire font library at once.

**Why:** HTML remains searchable, accessible, copyable, and lightweight, while the image shows the exact visual character style and can support image search without making every font page heavy.

**How to apply:** Add unique, compressed previews first to high-traffic or strategically important font pages; keep descriptive alt text, intrinsic dimensions, and lazy loading.
