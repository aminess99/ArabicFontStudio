name: Site icon branding
description: Branding decision for the site's favicon and header logo
---

The blue play icon extracted from the YouTubeThumbnailAI artwork is the browser and app icon. The full wordmark remains the header logo so the navigation keeps its readable brand name.

**Why:** The compact icon remains legible at favicon sizes, while the full wordmark is still useful when users need to identify the site in the interface.

**How to apply:** Keep the icon assets transparent and square for favicon, shortcut-icon, and Apple touch icon usage. Do not replace the header wordmark with the square icon unless the layout is intentionally redesigned.
